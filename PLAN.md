# Delivery map

This replaces the prototype's phased plan. Architectural context and extension recipes live in docs/.

Implemented: SaaS identity/workspaces, PostgreSQL schema/migrations, provider adapters, bounded
agent workflow, durable reports, evidence validation, practice plans, quotas, optional Stripe billing,
public/authenticated frontend, contract tests, browser suite, deployment definitions and contributor docs.

External setup: Google OAuth client/consent configuration; model account keys/entitlements;
Stripe prices, webhook and portal; domain/HTTPS; production database/backups; operating policies.

Future scope (not presented as completed): real-time bidirectional voice, coding execution sandbox,
additional interview modes, email delivery, full account self-deletion, automated retention,
calibrated role-specific score benchmarks and enterprise identity administration.

Prioritize validated learning outcomes and reliable voice latency before adding more interview modes.
